# Changelog

All notable project changes are recorded here. This project follows a simple versioned release history.

## [0.1.0] — initial experimental baseline

This is the first standalone project baseline, not a stable release.

- Added the KWin WindowSwitcher KPackage.
- Added the centered thumbnail carousel for 1–6 windows.
- Added the adaptive thumbnail grid for 7+ windows.
- Added application icons, window captions, desktop labels, and minimized state.
- Added keyboard hints and card mouse activation.
- Added user-level install and uninstall scripts.
- Added structural tests and QML/shell CI checks.
- Added project documentation, roadmap, and concept preview.
- Adjusted KWin window-ID role forwarding after the first Fedora KDE runtime test.

### Not yet verified

- Live KWin behavior on Fedora KDE / Plasma 6.8.x.
- Multi-monitor and high-DPI behavior.
- Performance under large window counts.
