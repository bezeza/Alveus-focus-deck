# Security policy

Alveus Focus Deck is a local KWin theme. It is not intended to collect or transmit window titles, screenshots, telemetry, or other session data.

## Reporting a security issue

Please do not publish exploit details or sensitive desktop information in a public issue. If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, contact the maintainer privately through the GitHub profile: https://github.com/bezeza.

For ordinary visual bugs, use the public bug report template.
